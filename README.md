# Vue Multi Tenant Boilerplate Dashbaord

## Environments

```
1. Production

==> Branch Name: main

2. Development

==> Branch Name: develop

```

## Install

```sh

git clone https://github.com/awal-solution/vue-multi-tenant-boilerplate.git
cd  vue-multi-tenant-boilerplate.git
npm i
```

## Start development

```sh
npm run dev
```

## Build for production

```sh
npm run build
```
